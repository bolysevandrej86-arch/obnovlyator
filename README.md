# ⚡ Обновлятор

Автообновление программ на Windows через **winget** (+ pip/npm), очистка
системы, менеджер автозагрузки и диагностика — в одном окне, с жизнью
в трее и самообновлением через GitHub Releases.

[![Скачать](https://img.shields.io/badge/скачать-Obnovlyator.exe-blue)](../../releases/latest)
[![Версия](https://img.shields.io/badge/версия-1.7.5-green)](../../releases)

## Возможности

- 📦 **Обновления программ** — сканирование и тихая установка через winget,
  опционально pip-пакеты и глобальные npm-пакеты.
- 🔀 **Категории VPN** — пакеты делятся на «С VPN» и «Без VPN»; при
  «Обновить всё» приложение само подключит VPN, обновит и отключит его.
- 🧹 **Очистка** — установщики winget, %TEMP%, кэши pip и браузеров,
  кэш Центра обновления, WinSxS (DISM) — с отчётом по корзине и загрузкам.
- 🗑 **Мусор** — предустановленный софт, рекламные UWP-приложения,
  задачи планировщика, остатки удалённых программ.
- 🚀 **Автозагрузка** — что стартует с Windows; отключение обратимо.
- 🩺 **Проверки** — SFC, DISM, chkdsk, проблемные устройства, установка
  драйверов через Windows Update, SMART дисков, целостность файлов.
- 🕘 **История и статистика** — всё, что сделано, с графиком за 14 дней.
- ⬆️ **Самообновление** — релизы на GitHub Releases, подписанный манифест,
  автоматический откат, если новая версия не поднялась.
- 🗑 **Удаление программы** — генерирует bat-деинсталлятор (Python не нужен).

## Установка

1. Скачайте `Obnovlyator.exe` со страницы
   [Releases](../../releases/latest).
2. Положите в любую папку, доступную для записи (например,
   `%LOCALAPPDATA%\Programs\Обновлятор`) — рядом с exe создаются
   `config.json`, `history.jsonl` и `logs\`.
3. Запустите. Обновления программы приходят сами; проверка — также кнопкой
   в трее и в Настройках.

### Запуск из исходников

Требуется Python 3.10+:

```bat
pip install -r requirements.txt
python main.py
```

Самопроверки:

```bat
python main.py --selftest          REM конфиг + winget + скан + VPN
python main.py --selftest --no-net REM без обращения к сети
python main.py --smoke             REM UI собирается скрыто и закрывается
```

## Как пользоваться

1. **«Проверить обновления»** — карточки: имя, ID, текущая → новая версия,
   статус.
2. Разделы сверху: **Все / Без VPN / С VPN**, поиск, сортировка.
   **F5** — обновить, **Ctrl+A** — выделить всё. Состояние видно в
   заголовке окна («4 обновл.», «обновление…»).
3. **Правый клик по пакету**: VPN-категория, «Игнорировать эту версию»,
   «ℹ О пакете», «📜 Лог установки».
4. **«Обновить всё»** — два этапа: обычные пакеты, затем через VPN
   (с автоматическим подключением/отключением VPN, если настроено).

### Разделы

- **🧹 Очистка** — установщики winget (`%TEMP%\WinGet`), временные файлы
  старше суток, кэш pip, кэш Центра обновления (нужен админ), WinSxS через
  DISM, кэши Chrome/Edge/Firefox. Отчёты: корзина и старые файлы в
  «Загрузках» (только показ). Кнопка **«✨ Навести порядок»** выбирает все
  безопасные цели и заодно убирает осиротевшие `_MEI*`-папки PyInstaller.
- **🗑 Мусор** — поиск по 4 секциям: программы-мусор из реестра, рекламные
  UWP-приложения, задачи планировщика вне Microsoft, возможные остатки в
  Program Files. Ничего не удаляется само — всё с подтверждением.
- **🕘 История** — сводка «за 30 дней / за всё время», график по дням,
  экспорт в txt/csv. Бэкап софта: `winget export` → `winget import`.
- **🚀 Автозагрузка** — Run (HKCU/HKLM) и папки автозагрузки. Отключение
  обратимо: записи переезжают в хранилище Обновлятора, ярлыки получают
  суффикс `.disabled`.
- **🩺 Проверки** — только диагностика: целостность приложения, проблемные
  устройства, поиск и установка драйверов через Windows Update, SMART,
  DISM/SFC/chkdsk, точка восстановления и мастер восстановления системы.

## Трей и уведомления

При закрытии окно сворачивается в трей («Открыть», «Проверить обновления»,
«Обновить всё», «Выход») — по расписанию всё работает в фоне. Находки и
результаты приходят уведомлениями Windows. Оба поведения отключаются в
Настройках.

## Самообновление приложения

- Фоновая проверка GitHub Releases (интервал в Настройках) + кнопка в трее.
- Каналы: **stable / beta / nightly**.
- Скачивание с докачкой после обрыва; **SHA-256** файла и **ed25519-подпись
  манифеста** проверяются перед запуском — подмена исключена.
- Подмена exe атомарна, всегда с бэкапом; если новый exe не смог подняться —
  **автоматический откат** на предыдущую версию и тост.
- Обновление ставится только с согласия («сейчас» / «при выходе» /
  «пропустить версию»). После успешного старта — один тост «обновление
  завершено», без повторов.

## Права администратора

Без админа всё работает — Windows покажет UAC там, где нужно. Кнопка
**«🔑 Перезапустить от администратора»** в сайдбаре делает тихие обновления,
WinSxS и кэш обновлений без UAC на каждый пакет.

## Безопасность

- Все установки идут через winget, который проверяет SHA256 установщиков
  по официальным манифестам; приложение ничего не скачивает напрямую
  (кроме самого себя — с проверкой подписи).
- Проверка VPN по IP принимает только https-URL.
- Второй экземпляр не запускается: повторный запуск показывает окно
  первого (оно может быть свёрнуто в трей).
- Приложение никуда не отправляет данные: конфиг, история и логи —
  локально.

## Настройки (окно ⚙ или config.json)

| Поле | Что делает |
|---|---|
| `vpn_processes` / `vpn_adapters` | подстроки имён VPN-процессов / адаптеров |
| `vpn_connect_cmd` / `vpn_disconnect_cmd` | команды включения/выключения VPN |
| `vpn_disconnect_after` | отключать VPN, если приложение подключило его само |
| `vpn_home_country` / `vpn_ip_url` | проверка «не домой ли смотрит IP» (https) |
| `vpn_kill_switch` | прерывать загрузку VPN-пакета при обрыве VPN |
| `categories` | какие пакеты обновляются через VPN |
| `auto_interval_hours` | автопроверка каждые N часов (0 — выключена) |
| `auto_update_all` | при автопроверке сразу обновлять всё найденное |
| `night_mode` | автообновление «всё» только в 23:00–07:00 |
| `update_pip` / `update_npm` | pip- и npm-пакеты (нужны установленные Python / Node.js) |
| `winget_extra_args` | доп. аргументы winget, напр. `--scope user` |
| `timeout_sec` / `retries` | таймаут на пакет и повторные попытки |
| `start_with_windows` | автозапуск приложения |
| `theme_mode` | `dark` / `light` / `system` |
| `minimize_to_tray` | закрывать окно = свернуть в трей |
| `notify_enabled` | уведомления Windows |
| `restore_point` | точка восстановления перед «Обновить всё» |
| `perf_mode` | режим слабых ПК: меньше фона, анимаций и графики |
| `per_monitor_dpi` | per-monitor DPI v2 (по умолчанию system-aware) |
| `selfupdate_enabled` / `update_channel` | самообновление и канал (stable/beta/nightly) |
| `selfupdate_check_hours` | интервал проверки релизов |
| `blocked_packages` | чёрный список — никогда не обновлять |
| `pinned_packages` | закрепление версий (`numpy=1.26.4`) |
| `min_free_gb` | не начинать обновления при малом месте на диске |
| `failed_updates` / `ignored_updates` | «ошибка ранее» и скрытые вручную пакеты |

Повреждённый `config.json` заменяется значениями по умолчанию (битый
сохраняется как `config.json.broken`, предыдущий — `config.json.bak`).

## Защита от ошибок

- Таймауты на все внешние процессы; зависший установщик убивается вместе
  с дочерними, кнопка **«Остановить»** прерывает обновление.
- Ошибка пакета → повторная попытка → карточка с человеческим объяснением;
  остальные пакеты продолжают обновляться.
- **Kill-switch VPN**: обрыв VPN во время загрузки — загрузка мгновенно
  прерывается.
- **Точка восстановления** (по желанию) перед «Обновить всё».
- Пакет, который не скачался, помечается «ошибка ранее» и не предлагается,
  пока не выйдет новая версия (вернуть: правый клик → «Снова предлагать»).
- Ошибки движка не роняют окно: UI получает только события из очереди.
- Весь журнал дублируется в `logs\obnovlyator.log` с ротацией по суткам.

## Слабые ПК и малые экраны

- **Режим слабых ПК** — меньше фоновых задач, анимаций, графика; на машинах
  с ≤ 6 ГБ RAM или ≤ 4 ядрами включается автоматически.
- Окно адаптируется под 1366×768 и меньше, сайдбар прокручивается.
- DPI: system-aware по умолчанию; per-monitor v2 — `per_monitor_dpi: true`.

## Удаление программы

Настройки → «🗑 Удалить Обновлятор»: убирает автозапуск, настройки,
историю, журналы и файлы программы (генерируется bat-деинсталлятор —
работает на любом ПК, Python не нужен). Действие необратимо.

## Сборка в .exe

```bat
build_exe.bat
```

Получится `dist\Obnovlyator.exe` — один файл без Python на машине.
Релизные сборки (подписанный манифест, публикация на GitHub Releases)
делает `build_release.py`.

Примечание: onefile-сборки иногда ловят ложные срабатывания антивирусов —
это норма для PyInstaller; при необходимости добавьте папку в исключения.

## Структура

```
core.py        — движок: winget/pip/npm, VPN, конфиг, точки восстановления
cleanup.py     — очистка установщиков, кэшей, браузеров, DISM, отчёты
bloat.py       — поиск мусора: программы, UWP, задачи, остатки
startup.py     — автозагрузка (Run HKCU/HKLM, папки)
diag.py        — проверки: SFC/DISM/chkdsk, драйверы, SMART, восстановление
history.py     — история действий и статистика
tray.py        — иконка в трее и уведомления
ui.py          — интерфейс (CustomTkinter)
main.py        — точка входа (+ --selftest / --smoke)
selfupdate.py  — самообновление: проверка релизов, загрузка, подмена exe
build_exe.bat / build_release.py / app.ico — сборка
```
